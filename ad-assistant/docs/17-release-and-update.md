# 17 发布与更新

## 发布原则

发布必须可回滚、可追踪、可灰度。

## 桌面端更新

修改自动更新逻辑属于重大变更，必须先确认。

桌面端发布必须检查：
- Tauri 权限
- 本地服务启动方式
- sidecar 签名
- 安装包来源
- 版本号
- 更新通道

## 云端发布

云端发布必须检查：
- 数据库迁移
- Provider 配置
- API 兼容性
- 限流配置
- 日志脱敏
- 回滚方案

## 版本策略

建议版本：
- `0.1.x`：MVP 内测
- `0.2.x`：付费试点
- `1.0.x`：正式商业发布

## 发布前闸门

必须通过：
- 登录授权测试
- 设备绑定测试
- OCR 最小闭环测试
- 额度扣除或免费记录测试
- provider_call_log 写入测试
- 安全检查
