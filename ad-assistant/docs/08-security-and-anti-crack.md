# 08 安全与防破解

## 安全优先级

安全 > 稳定 > 可维护 > 可扩展 > 功能数量 > 开发速度

## 必须实现

MVP 必须具备：
- 云端授权校验
- 设备绑定
- Token 刷新机制
- 离线授权缓存
- 请求限流
- 风控日志
- 异常设备封禁
- 点数云端扣除
- Provider 调用日志
- 成本统计

## Token 规则

禁止本地保存明文 Token。

桌面端必须：
- 使用系统安全存储或加密存储保存 refresh token
- access token 短有效期
- refresh token 可撤销
- logout 后清理本地敏感凭据

修改 Token 机制属于重大变更，必须先确认。

## 设备绑定

设备绑定信息必须由云端确认。

客户端可提交设备指纹，但客户端不能决定：
- 是否已授权
- 是否超过设备数量
- 是否封禁

## 离线授权缓存

离线缓存只用于短时间容错。

离线缓存必须包含：
- 用户 ID
- 设备 ID
- 授权过期时间
- 已允许功能列表
- 云端签名

客户端不得自行延长离线授权。

## 风控日志

必须记录：
- 登录失败
- Token 刷新失败
- 设备绑定失败
- 授权失败
- 额度不足
- 高频调用
- Provider 调用失败
- 异常设备

## 禁止

禁止：
- API Key 放客户端
- 客户端直接扣点
- 客户端决定套餐
- 绕过云端授权
- 未授权调用高级 AI
- 新增远程命令执行能力
- 放宽文件系统权限
- 静默修改自动更新逻辑
