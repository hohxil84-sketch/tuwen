# 08 安全与防破解

## 安全优先级

安全 > 稳定 > 可维护 > 可扩展 > 功能数量 > 开发速度

## 必须实现

MVP 必须具备：
- 云端授权校验
- 设备绑定
- Token 刷新机制
- 离线授权缓存
- 请求限流
- 风控日志
- 异常设备封禁
- 点数云端扣除
- Provider 调用日志
- 成本统计

## Token 规则

禁止本地保存明文 Token。

桌面端必须：
- 使用系统安全存储或加密存储保存 refresh token
- access token 短有效期
- refresh token 可撤销
- logout 后清理本地敏感凭据

修改 Token 机制属于重大变更，必须先确认。

## 设备绑定

设备绑定信息必须由云端确认。

客户端可提交设备指纹，但客户端不能决定：
- 是否已授权
- 是否超过设备数量
- 是否封禁

## 离线授权缓存

离线缓存只用于短时间容错。

离线缓存必须包含：
- 用户 ID
- 设备 ID
- 授权过期时间
- 已允许功能列表
- 云端签名

客户端不得自行延长离线授权。

## 风控日志

必须记录：
- 登录失败
- Token 刷新失败
- 设备绑定失败
- 授权失败
- 额度不足
- 高频调用
- Provider 调用失败
- 异常设备

## 禁止

禁止：
- API Key 放客户端
- 客户端直接扣点
- 客户端决定套餐
- 绕过云端授权
- 未授权调用高级 AI
- 新增远程命令执行能力
- 放宽文件系统权限
- 静默修改自动更新逻辑

## RBAC 角色权限体系（S05-R03）

### 角色定义

| 角色 | 说明 |
|------|------|
| `admin` | 管理员 — 全部权限 |
| `operator` | 运维 — 只读管理（不可授权积分） |
| `user` | 普通用户 — 无管理权限 |

### 权限点

| 权限代码 | 说明 | admin | operator |
|----------|------|-------|----------|
| `users:read` | 查看用户列表 + 积分账户 | ✅ | ✅ |
| `orders:read` | 查看充值订单 | ✅ | ✅ |
| `credits:grant` | 赠送积分 | ✅ | ❌ |
| `provider_logs:read` | 查看 Provider 调用日志 | ✅ | ✅ |
| `usage_events:read` | 查看使用事件 | ✅ | ✅ |

### 实现要点

- 权限检查在服务端通过 `PermissionChecker` 依赖完成
- 角色存储于 `users.role` 字段（VARCHAR(20)，默认 `"user"`）
- `ADMIN_USER_IDS` 配置保留为 bootstrap 回退：当用户 role 无权限但 user_id 在白名单中时，仍允许访问（用于首次启动时提升第一个管理员）
- 不信任客户端传入的角色字段
- 未定义角色/权限默认拒绝
