# 14 AI Agent 协作流程

## 角色

Codex：
- 架构设计
- 任务拆分
- 代码 Review
- 安全检查
- API 检查
- 数据库检查
- Provider 检查
- 成本检查

Claude Code + DeepSeek：
- 按任务单执行开发
- 改文件
- 跑命令
- 修 Bug

## 规则

1. 一个模块一个对话。
2. 一个模块一个 Git 分支。
3. 没有任务单，不允许写代码。
4. 没有用户确认，不允许开发未来功能。
5. Codex 优先 Review，不随便大规模改代码。
6. Claude Code + DeepSeek 只负责执行任务单。

## 标准流程

1. 用户提出目标。
2. Codex 生成或修订任务单。
3. 用户确认任务单。
4. Claude Code + DeepSeek 按任务单开发。
5. Claude Code + DeepSeek 输出修改、测试、风险。
6. Codex Review。
7. 用户确认是否合并或进入下一任务。

## 任务单闸门

任务单必须明确：
- 本次只开发什么
- 本次不开发什么
- 允许修改哪些文件
- 禁止修改哪些文件
- 验收标准
- 测试方式
- 是否允许新增依赖
- 是否涉及重大变更

缺少以上任一项，任务单无效。
