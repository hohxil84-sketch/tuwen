# 15 编码规范

## 总原则

代码必须清晰、可审计、可回滚。

不得为了速度牺牲安全。

## TypeScript

要求：
- 开启严格类型检查
- 禁止使用 `any` 绕过类型，除非有注释说明
- API 类型来自 `shared/typescript`
- UI 组件不得包含 Provider Key、扣费逻辑、套餐最终判断

## Python

要求：
- 使用类型标注
- Provider 返回统一结构
- 错误码统一映射
- 日志必须脱敏
- 不得记录明文 Token、密码、API Key

## API

要求：
- 所有 API 返回统一响应结构
- 所有请求带 request_id 或由服务端生成 request_id
- 所有错误使用统一错误码
- 修改契约必须先确认

## 数据库

要求：
- 迁移脚本必须可回滚
- 扣费必须有流水
- Provider 调用必须有日志
- Token 只能存 hash 或加密值

## 安全编码

禁止：
- 拼接未校验命令
- 拼接 SQL
- 明文保存凭据
- 前端保存 API Key
- 日志输出敏感字段
- 客户端决定权限和扣费
