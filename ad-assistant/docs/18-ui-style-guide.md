# 18 UI 风格指南

## 产品气质

面向图文广告行业的一线工作台。

UI 应该：
- 直接
- 稳定
- 高效
- 易扫读
- 像生产工具，不像营销页面

## 桌面端布局

MVP 建议三栏结构：
- 左侧：功能按钮和历史记录入口
- 中间：图片上传、预览、OCR 结果
- 右侧：授权状态、额度、使用统计

## 控件原则

使用按钮化工作流：
- 上传图片
- 开始 OCR
- 复制结果
- 保存历史
- 查看历史

避免通用聊天输入框作为主入口。

## 状态展示

必须清晰展示：
- 登录状态
- 设备授权状态
- 当前套餐
- AI 算力余额
- 本次 OCR 状态
- 本次是否扣费

## 禁止

禁止：
- 把 MVP 做成聊天机器人
- 用大面积营销式 Hero 替代工作台
- 隐藏授权和额度状态
- 用含糊文案掩盖扣费
