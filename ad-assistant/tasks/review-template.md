## 审查重点

- 是否只实现任务单内容
- 是否存在越界开发
- 是否修改重大变更项
- 是否前端直连第三方 AI API
- 是否泄露 API Key 或 Token
- 是否客户端扣点
- 是否客户端决定套餐
- 是否绕过云端授权
- 是否所有 AI 调用经过 Provider 层
- 是否写入 provider_call_log
- 是否记录真实成本或可追溯估算成本
- 是否有测试
