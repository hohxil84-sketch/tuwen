## 是否允许新增依赖

不允许，除非本节明确写明依赖名称、用途和风险。

## 是否涉及重大变更

必须明确填写：是 / 否。

如果是，必须包含：
1. 修改原因
2. 风险点
3. 影响范围
4. 回滚方案
5. 是否兼容旧版本
6. 是否需要数据库迁移

## 安全检查

- 不下发 API Key 到客户端
- 不由客户端扣点
- 不由客户端决定套餐
- 不绕过云端授权
- 不明文保存 Token
- AI 调用写入 provider_call_log

## 完成输出要求

执行者完成后必须输出：
- 修改文件列表
- 实现内容
- 未实现内容
- 测试命令和结果
- 风险点
- 是否触发重大变更
